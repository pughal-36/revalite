# AI Development Prompts

This document records the prompts used during the development of REVA Lite.

## Prompt 1 — Architecture

### Prompt

I am building a small React + Vite frontend application called "REVA Lite" for an AI-assisted development assignment.

The application is a lightweight e-waste evaluation dashboard.

Constraints:
- React + Vite only
- Plain CSS
- No backend
- No database
- No authentication
- No external APIs
- No AI API integration
- Use local/mock data
- No unnecessary dependencies
- Keep the architecture simple
- Do not over-engineer the project

Planned features:
1. Dashboard statistics
2. Search devices
3. Filter devices by category and status
4. Device cards
5. Device details
6. Simple inspection form

For now, do not implement the application.

Inspect the existing Vite project and propose a simple component/file structure.

Explain:
- Components needed
- Responsibility of each component
- Where mock data should live
- How state should be managed
- How components should communicate

Do not install packages or modify files yet.
