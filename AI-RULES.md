# REVA Lite AI Development Rules

## Project

REVA Lite is a lightweight React + Vite frontend application for an AI-assisted development assignment.

## Technology

- React
- Vite
- JavaScript
- Plain CSS

## Constraints

- No backend
- No database
- No authentication
- No external APIs
- No AI API integration
- No unnecessary npm packages
- Use local mock data
- Keep the implementation beginner-friendly
- Prefer simple React state and props
- Avoid over-engineering

## Development Rules

1. Only modify files necessary for the requested feature.
2. Do not install dependencies unless they are genuinely necessary.
3. Do not rewrite unrelated existing code.
4. Explain the proposed changes before making major changes.
5. Keep components small and readable.
6. Prefer simple solutions over abstractions.
7. After implementation, identify potential bugs or improvements.
8. Do not create backend infrastructure.
9. Do not add features that were not requested.

## Application Features

The application will contain:

- Dashboard statistics
- Device search
- Category filtering
- Status filtering
- Device cards
- Device details
- Simple inspection form

## Data

All application data will initially be local mock data.
